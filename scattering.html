Scattering Theory

Introduction

In undergrad we often formulate the solution to the delta-potential well in terms of reflection, transmission, and incoming waves.


In this case, the Hamiltonian is: \[ \hat H = \frac{\hat p^2}{2m} + \lambda\delta(x) \] and the continuum states with \(E\gt 0\) are doubly degenerate and have either even or odd parity.

This formulation of the solution requires us to restrict the scenario to only one incoming beam, and to additionaly pick a single direction for the incoming beam. In the example visualized above, we have an incoming beam moving from the left to the right. We can write this state, with a single incoming beam from the left, as: \[ \psi_k^{(+)}(x) = \phi_{\alpha, k}(x) + \sum_\beta \phi_{out, \beta} \] Here, the positive subscript \(k\) indicates that the incoming beam is travelling to the right and the \((+)\) superscript indicates that there is only one incoming beam. We also say that \(\phi(x)\) is some sort of plane wave.

The first term on the righthand side thus describes the incoming wave alone, while the second term, a summation, describes the outgoing waves. We can have outgoing waves in two channels-- the rightwards-moving channel and the leftwards-moving channel, which is represented in the variable of summation, \(\beta\).

The state with a single incoming beam travelling from right to left is similar: \[ \psi_{-k}^{(+)}(x) = \phi_{\alpha, -k}(x) + \sum_\beta \phi_{out, \beta} \] In both these cases, we have essentially prepared a single clean, incoming beam with well-defined momentum and fired it at the delta potential. It is also possible to build a wave packet which does not have one single momentum: \[ \psi(x) = \int_0^\infty dk\quad c(k-k_0)\psi^{(+)}_k(x), \quad \int dk |c(k-k_0)|^2\lt \infty \] where we write the state as a linear combination of \(\psi_k^{(+)}\)'s, which each have a single momentum, with expansion coefficient \(c(k-k_0)\) which is a square-integrable function of \(k\) that causes the wave packet to be strongly peaked around a certain momentum \(k_0\). We can even add a time-dependence: \[ \psi(x, t) = \int_0^\infty dk\quad c(k-k_0)\psi^{(+)}_k(x)e^{-iE_kt/\hbar} \] In these cases, we have a well-defined input; no matter how messy the result upon collision with the delta potential, once we rewind time enough, we should recover the clean, well-defined incoming plane wave or wave packet. Transition amplitudes. Say that we have a state \(|\psi^{(+)}_{\vec k, i}\rangle = |\psi^{(+)}_{\alpha E}\rangle\) which has incoming beam \(e^{i \vec k_0\cdot\vec r}\) that interacts with a potential and scatters. In preparing the incoming beam and making it interact with the potential, we have prepared the state \(|\psi^{(+)}_{\alpha E}\rangle\).

After scattering, we have an outgoing result over a scattering angle \(d\Omega\). We can place a detector so that it catches the outgoing result, and have the detector select for a plane wave with well-defined momentum, \(e^{i\vec k_f\cdot\vec r}\).



The probability amplitude of this ever happening and measuring \(e^{i\vec k_f\cdot\vec r}\) in the detector when the input was \(e^{i\vec k_0\cdot\vec r}\) is exactly: \[ \mathcal A_{\vec k_f\leftarrow \vec k_0} = \langle \psi^{(-)}_{\vec k_f} | \psi^{(+)}_{\vec k_0} \rangle \] since if we have a final \(e^{i\vec k_f\cdot\vec r}\) with a well-defined \(\vec k_f\), we really have the eigenstate \(\psi^{(-)}_{\vec k_f}\) as seen in the far future, which we assume is where the detector is.

If we have a well-defined initial energy in the distance past \(E\) and a well-defined final energy in the distant future \(E'\), then \(E\) must be equal to \(E'\) under conservation of energy. Thus we say that \[ \mathcal A_{\vec k_f\leftarrow \vec k_0} \propto \delta(E' - E) \mathcal S_{\beta\alpha}(E) \] where \(\mathcal S_{\beta\alpha}(E)\) is the scattering matrix, which we cover in more depth later.

Defining the eigenstates. We know that \(|\psi_{\alpha E}\rangle\) is a eigenstate of \(\hat H = \hat H_0 + \hat V\) where \(\hat V\) is local, meaning that it dies off as the particle gets further and further from the interaction center. Define: \[ \hat H | \psi_E\rangle = E |\psi_E\rangle, \quad \hat H_0|\phi_E\rangle = E|\phi_E\rangle \] Then \begin{align} \hat H | \psi_E\rangle &= (\hat H_0 + \hat V)|\psi_E\rangle = E|\psi_E\rangle \\ (E - \hat H_0)|\psi_E\rangle &= \hat V|\psi_E\rangle = |\chi\rangle \end{align} The naive solution to this is \(|\psi_E\rangle = \frac{1}{E-\hat H_0}|\chi\rangle\) plus a solution to the associated homogeneous equation (i.e. the case where \(|\chi\rangle = 0\)), so \(|\phi_E\rangle\), and indeed this is typically how the solution to an inhomogeneous equation is built. If we use \(|\psi_E\rangle = \frac{1}{E-\hat H_0}|\chi\rangle + |\phi_E\rangle\), we get: \[ (E - \hat H_0)|\psi_E\rangle = (E - \hat H_0)(\frac{1}{E-\hat H_0}|\chi\rangle + |\phi_E\rangle) = |\chi\rangle + (E-\hat H_0)|\phi_E\rangle = |\chi\rangle \] or, it \(|\chi\rangle\) is somehow 0: \[ (E - \hat H_0)|\psi_E\rangle = (E-\hat H_0)|\phi_E\rangle = 0 = |\chi\rangle \] which still holds without our solution for \(|\psi_E\rangle\) being 0 itself. However, \(E\) is in the spectrum of \(\hat H_0\), so this solution can diverge. We instead make \(E\) complex-- say it now obtains an imaginary component \(E'\), so that the total energy is \(E + iE'\). We take the limit as \(E'\to\pm 0^+\) and obtain two solutions for \(|\psi_E\rangle\): \begin{align} |\psi_E^\pm\rangle &= \frac{1}{E - \hat H_0 \pm i0^+}|\chi\rangle + |\phi_E\rangle \\ &= \frac{1}{E - \hat H_0 \pm i0^+}\hat V|\psi^\pm_E\rangle + |\phi_E\rangle \\ &= \hat G_0^\pm(E)\hat V|\psi^\pm_E\rangle + |\phi_E\rangle \tag{1} \end{align} This is called the Lipmann-Schwinger equation. We will see later that these states \(|\psi_E^\pm\rangle\) correspond to the states we were introduced to earlier which are controlled in the past and future.

However for now, notice that this definition for \(|\psi^\pm_E\rangle\) is recursive-- the right hand side itself contains \(|\psi^\pm_E\rangle\). We can expand this: \begin{align} |\psi_{\alpha E}^\pm\rangle &= |\phi_{\alpha E}\rangle + \hat G_0^\pm(E)\hat V|\psi^\pm_E\rangle \\ &= \sum_{n=0}^\infty \left[\hat G_0^\pm(E)\hat V\right]^n|\phi_{\alpha E}\rangle \end{align} We will later see that we can define what is called the T-Matrix, where: \[ T_{\beta\alpha}(E) = \langle\phi_{\beta E} | \hat V | \psi^+_{\alpha E}\rangle = \langle\phi_{\beta E} | \hat V \left[\hat G_0^+(E)\hat V\right]^n | \phi_{\alpha E}\rangle \] where the last expression is a transition amplitude in perturbation series, or what is known as the Born series.

Möller Operators

Say that at time \(t_f\), we have an incoming wavepacket \(|\phi_{in}(t_f)\rangle\) in a system that has no perturbation, so that \(\hat H = \hat H_0\). This wavepacket has not interacted with the perturbation at all and has simply been propagating freely.

What if we want to know what the wavepacket looked like if it HAD interacted with a perturbation \(\hat V\) at an earlier time \(t_1\)? Let's say that time \(t_f\) occurs in the far future compared to \(t_1\), so that \(t_f = \infty\) by comparison.

No matter what the wavepacket is, we can "rewind" it back in time using the unitary time-evolution operator: \[ e^{-i\hat H_0 t/\hbar}|\phi_{in}(t_f)\rangle, \quad t \lt 0 \] Notice that here, we use the unperturbed Hamiltonian, and thus using this operator to "rewind" time is rewinding time where no perturbation ever interacted with the wavepacket.

Say that we rewind back into a time in the far past, way before \(t_1\), to \(t_0 = -\infty\), so that we have \(|\phi_{in}(t_0)\rangle\). In the figure below, we have followed the line straight from the rightmost point, \(t_f\) to the leftmost point, \(t_0\).
Now, we propagate the wavepacket way forward in time using \(\hat H = \hat H_0 + \hat V\), until the perturbation has come and gone: \[ e^{i\hat H t/\hbar}|\phi_{in}(t_0)\rangle, \quad t \lt 0 \] so in the figure below, we have followed the line from the leftmost point, \(t_0\) to the rightmost point, \(t_f\).
We have essentially taken an incoming wavepacket at time \(t_0\) and allowed it to interact with a perturbation, which means we have obtained \(|\psi^{(+)}\rangle\), the scattering state which is controlled in the past: \[ |\psi^{(+)}\rangle = \lim_{t\to-\infty}e^{i\hat Ht/\hbar}e^{-i\hat H_0t/\hbar} | \phi_{in}\rangle \] We can think of it like branching universes; at time \(t_0\) we have a single state, \(|\phi_{in}(t_0)\rangle\). We then branch off into two different possbilities-- either we reach time \(t_f\) having never seen a perturbation, in which case we are in state \(|\phi_{in}(t_f)\rangle\), or we did experience a perturbation before arriving at time \(t_f\), in which case we are in state \(|\psi^{(+)}\rangle\).

To map from one possible future which is unperturbed, \(|\phi_{in}(t_f)\rangle\), to another possible future which esperienced the full Hamiltonian, \(|\psi^{(+)}\rangle\), we have applied the Möller operator \(\hat\Omega_+\): \[ \hat\Omega_+ = \lim_{t\to-\infty}e^{i\hat Ht/\hbar}e^{-i\hat H_0t/\hbar} \] so that \(|\psi^{(+)}\rangle = \hat\Omega_+|\phi_{in}(t_f)\rangle\).

This operator has a few properties that we don't have time to get into; it is unitary for a finite time and an isometry in its complete form above. It, as we have discussed, propagates a state freely (so without perturbation) far back into time, and then propagates it forward using the full propagator (so with perturbation).

We apply this operator when we want there to be a boundary condition in the past, in this case that \(|\phi_{in}(t_f)\rangle\) and \(|\psi^{(+)}\rangle\) coincide at \(t_0=-\infty\).

There is also a Möller operator for the case where there is a boundary condition in the future: \[ \hat\Omega_- = \lim_{t\to+\infty}e^{i\hat Ht/\hbar}e^{-i\hat H_0t/\hbar} \] which matches some \(|\phi_{out}(t_0)\rangle\) and a \(|\psi^{(-)}\rangle\) in the far future so that \(|\psi^{(-)}\rangle = \hat\Omega_-|\phi_{out}(t_0)\rangle\).

In other words, the Möller operators give us the ability to map from the unperturbed Hilbert space, e.g. plane waves, to the continuum Hilbert space of the full Hamiltonian, which are the scattering states of the full Hamiltonian.

Intertwining relations. We can now demonstrate the spectrum of the unperturbed Hamiltonian and the continuum eigenstates of the full Hamiltonian coincide; since we map from the first to the second using the Möller operators. The demonstration proceeds as follows:

We introduce time propagator \(e^{i\hat H\tau/\hbar}\), and then later make \(\tau = 0\). \begin{align} e^{i\hat H\tau/\hbar}\hat\Omega_\pm &= \textcolor{blue}{e^{i\hat H\tau/\hbar}} \lim_{t\to\mp\infty} e^{i\hat H t/\hbar}e^{-i\hat H_0 t/\hbar} \\ &= \lim_{t\to\mp\infty} \textcolor{blue}{e^{i\hat H\tau/\hbar}}e^{i\hat H t/\hbar}e^{-i\hat H_0 t/\hbar}\textcolor{red}{e^{-i\hat H_0\tau/\hbar}e^{i\hat H_0\tau/\hbar}} \\ &= \lim_{t\to\mp\infty} e^{i\hat H(t + \tau)/\hbar} e^{-i\hat H_0(t + \tau)/\hbar}e^{i\hat H_0\tau/\hbar} \\ &= \hat\Omega_\pm e^{i\hat H_0\tau/\hbar} \end{align} since we take the limit as \(t\to\mp\infty\), the extra time shift \(tau\) doesn't change the fact that we have recovered the Möller operators. We now take the time derivative with respect to \(\tau\) (not \(t\)) on both sides: \begin{align} e^{i\hat H\tau/\hbar}\hat\Omega_\pm &= \hat\Omega_\pm e^{i\hat H_0\tau/\hbar} \\ \frac{i\hat H}{\hbar}e^{i\hat H\tau/\hbar}\hat\Omega_\pm &= \hat\Omega_\pm e^{i\hat H_0\tau/\hbar}\frac{i\hat H_0}{\hbar} \\ \text{For } \tau &= 0 \text{:}\\ \hat H \hat\Omega_\pm &= \hat\Omega_\pm\hat H_0 \end{align} this final statement is called intertwining relations. Now, if we have unperturbed eigentates \(|\phi_E\rangle\) so that \(\hat H_0|\phi_E\rangle = E|\phi_E\rangle\): \begin{align} \hat H \hat\Omega_\pm|\phi_E\rangle &= \hat\Omega_\pm\hat H_0|\phi_E\rangle \\ \hat H |\psi^{(\pm)}\rangle &= E|\psi^{(\pm)}\rangle \end{align} Notice how a single unperturbed eigenstate with energy \(E\), \(|\phi_E\rangle\), yields both scattering states \(|\psi^{(+)}\rangle\) and \(|\psi^{(-)}\rangle\) using the Möller operators, and that it has the same energy as both of them. These scattering states are the continuum states of the full Hamiltonian.

In other words, the range of allowed energies for \(|\phi_E\rangle\) are exactly the same as the range of allowed energies for the continuum states of the full Hamiltonian. Thus their spectrums are the same, or: \[ \sigma_C(\hat H_0) = \sigma_C(\hat H). \] The Lipmann-Schwinger equations. In order to actually compute the Möller operators, we need the Lipmann-Schwinger equation, which has many forms. We find the time-dependent form here, then re-do the demonstration of (1) more rigorously.

We now know that \(|\psi^{(+)}(t)\rangle = \hat\Omega_+|\phi_{in}(t)\rangle\) for a \(|\psi^{(+)}(t)\rangle\) and a \(|\phi_{in}(t)\rangle\) which coincide in the distance past, \(t = -\infty\). We start by rewriting \(\hat\Omega_+\) like so: \begin{align} \hat\Omega_+ &= \lim_{t_0\to-\infty}e^{i\hat Ht_0/\hbar}e^{-i\hat H_0t_0/\hbar} \\ &= \hat 1 - \lim_{t_0\to-\infty}\int_{t_0}^0\frac{d}{dt'}\left\{e^{i\hat H t'/\hbar}e^{-i\hat H_0t'/\hbar}\right\}dt' \end{align} We can show that this is an equivalent way to write it: \begin{align} \hat 1 - \lim_{t_0\to-\infty}\int_{t_0}^0\frac{d}{dt'}\left\{e^{i\hat H t'/\hbar}e^{-i\hat H_0t'/\hbar}\right\}dt' &= \hat 1 - \lim_{t_0\to-\infty}\left[e^{i\hat H t'/\hbar}e^{-i\hat H_0t'/\hbar}\right]_{t_0}^0 \\ &= \hat 1 - \lim_{t_0\to-\infty} \left[e^0e^0 - e^{i\hat H t_0/\hbar}e^{-i\hat H_0t_0/\hbar}\right] \\ &= \hat 1 - \lim_{t_0\to-\infty} \left[\hat 1 - e^{i\hat H t_0/\hbar}e^{-i\hat H_0t_0/\hbar}\right] \\ &= \lim_{t_0\to-\infty}e^{i\hat H t_0/\hbar}e^{-i\hat H_0t_0/\hbar} \\ &= \hat\Omega_+ \end{align} Anyway, from this version, we can continue by actualy expanding the integrand: \begin{align} \hat\Omega_+ &= \hat 1 - \lim_{t_0\to-\infty}\int_{t_0}^0\frac{d}{dt'}\left\{e^{i\hat H t'/\hbar}e^{-i\hat H_0t'/\hbar}\right\}dt' \\ &= \hat 1 - \lim_{t_0\to-\infty} \int_{t_0}^0 \left\{ e^{i\hat H t'/\hbar}\left(-\frac{i\hat H_0}{\hbar}\right)e^{-i\hat H_0t'/\hbar} + \left(\frac{i\hat H}{\hbar}\right)e^{i\hat H t'/\hbar}e^{-i\hat H_0t'/\hbar} \right\}dt' \\ &= \hat 1 - \lim_{t_0\to-\infty} \int_{t_0}^0 \left\{ e^{i\hat H t'/\hbar}\left(-\frac{i\hat H_0}{\hbar}\right)e^{-i\hat H_0t'/\hbar} + e^{i\hat H t'/\hbar}\left(\frac{i\hat H}{\hbar}\right)e^{-i\hat H_0t'/\hbar} \right\}dt' \\ &= \hat 1 - \frac{i}{\hbar}\lim_{t_0\to-\infty} \int_{t_0}^0 \left\{ -e^{i\hat H t'/\hbar}\hat H_0 e^{-i\hat H_0t'/\hbar} + e^{i\hat H t'/\hbar}\hat He^{-i\hat H_0t'/\hbar} \right\}dt' \\ &= \hat 1 - \frac{i}{\hbar}\lim_{t_0\to-\infty} \int_{t_0}^0 \left\{ e^{i\hat H t'/\hbar}\hat He^{-i\hat H_0t'/\hbar} - e^{i\hat H t'/\hbar}\hat H_0 e^{-i\hat H_0t'/\hbar} \right\}dt' \\ &= \hat 1 - \frac{i}{\hbar}\lim_{t_0\to-\infty} \int_{t_0}^0 \left\{ e^{i\hat H t'/\hbar} \left[ \hat H-\hat H_0 \right] e^{-i\hat H_0t'/\hbar} \right\}dt' \\ &= \hat 1 - \frac{i}{\hbar}\lim_{t_0\to-\infty} \int_{t_0}^0 \left\{ e^{i\hat H t'/\hbar} \hat V e^{-i\hat H_0t'/\hbar} \right\}dt' \\ \end{align} We see that the integrand propogates a state back by time \(t'\), applies the perturbation \(\hat V\), then propagates the perturbed state forward by time \(t'\). The integral here clearly takes the sum of all states that result from this procedure, over all different "time trajectories" through varying \(t'\)'s.

We now plug in our result above to \(|\psi^{(+)}\rangle = \hat\Omega_+|\phi_{in}\rangle\): \begin{align} |\psi^{(+)}(t)\rangle &= \hat\Omega_+|\phi_{in}(t)\rangle \\ &= \left( \hat 1 - \frac{i}{\hbar}\lim_{t_0\to-\infty} \int_{t_0}^0 \left\{ e^{i\hat H t'/\hbar} \hat V e^{-i\hat H_0t'/\hbar} \right\}dt' \right) |\phi_{in}(t)\rangle \\ &= |\phi_{in}(t)\rangle - \frac{i}{\hbar}\lim_{t_0\to-\infty} \int_{t_0}^0 \left\{ e^{i\hat H t'/\hbar} \hat V e^{-i\hat H_0t'/\hbar} \right\}|\phi_{in}(t)\rangle dt' \\ &= |\phi_{in}(t)\rangle - \frac{i}{\hbar}\lim_{t_0\to-\infty} \int_{t_0}^0 \left\{ e^{i\hat H t'/\hbar} \hat V \right\}|\phi_{in}(t+t')\rangle dt' \\ \end{align} We rename \(t + t'\) to \(t''\), so that \(t' = t''-t\) and \(dt''=dt'\)-- remember that \(t'\) is negative, so \(t''\) is an earlier time that \(t\). \begin{align} |\psi^{(+)}(t)\rangle &= |\phi_{in}(t)\rangle - \frac{i}{\hbar}\lim_{t_0\to-\infty} \int_{t_0}^0 \left\{ e^{i\hat H t'/\hbar} \hat V \right\}|\phi_{in}(t+t')\rangle dt' \\ &= |\phi_{in}(t)\rangle - \frac{i}{\hbar}\lim_{t_0\to-\infty} \int_{t+t_0}^{t+0} \left\{ e^{i\hat H (t''-t)/\hbar} \hat V \right\}|\phi_{in}(t'')\rangle dt'' \\ &= |\phi_{in}(t)\rangle + \frac{1}{i\hbar} \int_{-\infty}^t e^{-i\hat H (t-t'')/\hbar} \hat V |\phi_{in}(t'')\rangle dt'' \\ \end{align} Renaming \(t''\) as \(t'\): \begin{align} |\psi^{(+)}(t)\rangle &= |\phi_{in}(t)\rangle + \frac{1}{i\hbar} \int_{-\infty}^t e^{-i\hat H (t-t')/\hbar} \hat V |\phi_{in}(t')\rangle dt' \\ \end{align} This is the second version of the time-dependent Lipmann-Schwinger equation.

The integrand here is a state that freely propagates up until a time \(t'\) (recall that the perturbation is local and hence does not reach the state in the far past), then has the perturbation \(\hat V\) applied at time \(t'\). We then have driven propagation (so propagation with the full Hamiltonian) from time \(t'\) to a final time \(t\). Once again, the integral is over all of these "intermediate" times, \(t'\).

The following is the first version of the Lipmann-Schwinger equation: \begin{align} |\psi^{(+)}(t)\rangle &= |\phi_{in}(t)\rangle + \frac{1}{i\hbar} \int_{-\infty}^t e^{-i\hat H_0 (t-t')/\hbar} \hat V |\psi^{(+)}(t')\rangle dt' \\ \end{align} where we swap the roles of \(\hat H\) and \(\hat H_0\) and rearrange some terms. In this case, driven propagation occus until interaction at time \(t'\), then free propagation until time \(t\).

A discrepancy. Notice that so far, in our discussion of Möller operators, we have been working generally with wavepackets \(|\phi\rangle\) and \(|\psi^{(\pm)}\rangle\) which are well defined linear combinations of the continuum eigenstates. (except in the intertwining relations section, where we explicitly say that \(|\phi\rangle\) is an unperturbed eigenstate). Wavepackets eventually move on and disperse, hence they "get out of the way" of the perturbation as time passes. Generalized eigenstates, on the other hand, do not change with time (save for a phase factor). They are dependent on the distance from the interaction center, so they do still have asymptotic behaviors that look like plane waves, however they do not die off with time.

Because the Möller operators basically map two different "universes" to each other, this generalization is not a huge deal, and we can still use Möller operators with generalized eigenstates.

The time-dependent Lipmann-Schwinger equations as we have them defined right now do not work for generalized eigenstates of \(\hat H\) or \(\hat H_0\), because taking the integral starting from \(-\infty\) of a state that never dies off results in an infinite solution.

To use the time-dependent Lipmann-Schwinger equations with generalized eigenstates, we therefore have to add a regularization term. For example, the first version of the time-dependent Lipmann-Schwinger equation becomes: \begin{align} |\psi^{(+)}(t)\rangle &= |\phi_{in}(t)\rangle + \frac{1}{i\hbar} \lim_{\varepsilon\to0^+} \int_{-\infty}^t e^{-\varepsilon (t-t')/\hbar} e^{-i\hat H_0 (t-t')/\hbar} \hat V |\psi^{(+)}(t')\rangle dt' \\ \end{align} and the second version becomes: \begin{align} |\psi^{(+)}(t)\rangle &= |\phi_{in}(t)\rangle + \frac{1}{i\hbar} \lim_{\varepsilon\to0^+} \int_{-\infty}^t e^{-\varepsilon (t-t')/\hbar} e^{-i\hat H (t-t')/\hbar} \hat V |\phi_{in}(t')\rangle dt' \\ \end{align} so that the integral doesn't blow up. This is like having a wavepacket that mimicks the generalized eigenstates, since for \(\varepsilon\to0\), we converge on the stationary eigenstates.

The time-independent Lipmann-Schwinger equation. We now more rigorously demonstrate (1): \begin{align} |\psi^{(+)}(t)\rangle &= |\phi_{in}(t)\rangle + \frac{1}{i\hbar} \lim_{\varepsilon\to0^+} \int_{-\infty}^t e^{-\varepsilon (t-t')/\hbar} e^{-i\hat H_0 (t-t')/\hbar} \hat V |\psi^{(+)}(t')\rangle dt' \\ |\psi^{(+)}\rangle e^{-iEt/\hbar} &= |\phi_{in}\rangle e^{-iEt/\hbar} + \frac{1}{i\hbar} \lim_{\varepsilon\to0^+} \int_{-\infty}^t e^{-\varepsilon (t-t')/\hbar} e^{-i\hat H_0 (t-t')/\hbar} \hat V |\psi^{(+)}\rangle e^{-iEt'/\hbar} dt' \\ |\psi^{(+)}\rangle &= |\phi_{in}\rangle + \frac{1}{i\hbar} \lim_{\varepsilon\to0^+} \int_{-\infty}^t e^{-\varepsilon (t-t')/\hbar} e^{-i\hat H_0 (t-t')/\hbar} \hat V |\psi^{(+)}\rangle e^{-iEt'/\hbar}e^{iEt/\hbar} dt' \\ &= |\phi_{in}\rangle + \frac{1}{i\hbar} \lim_{\varepsilon\to0^+} \int_{-\infty}^t e^{-\varepsilon (t-t')/\hbar} e^{-i\hat H_0 (t-t')/\hbar} e^{iE(t-t')/\hbar} \hat V |\psi^{(+)}\rangle dt' \\ &= |\phi_{in}\rangle + \frac{1}{i\hbar} \lim_{\varepsilon\to0^+} \int_{-\infty}^t e^{-i(-i\varepsilon + \hat H_0 - E)(t-t')/\hbar} \hat V |\psi^{(+)}\rangle dt' \\ &= |\phi_{in}\rangle + \frac{1}{i\hbar} \lim_{\varepsilon\to0^+} \int_{-\infty}^t e^{-i(i\varepsilon - \hat H_0 + E)(t'-t)/\hbar} \hat V |\psi^{(+)}\rangle dt' \\ &= |\phi_{in}\rangle + \frac{1}{i\hbar} \lim_{\varepsilon\to0^+} \frac{1}{-i(i\varepsilon - \hat H_0 + E)/\hbar} \left[e^{-i(i\varepsilon - \hat H_0 + E)(t'-t)/\hbar}\right]_{-\infty}^t \hat V |\psi^{(+)}\rangle \\ &= |\phi_{in}\rangle + \frac{1}{i\hbar} \lim_{\varepsilon\to0^+} \frac{1}{-i(i\varepsilon - \hat H_0 + E)/\hbar} \left[e^0-0\right] \hat V |\psi^{(+)}\rangle \\ &= |\phi_{in}\rangle + \lim_{\varepsilon\to0^+} \frac{1}{i\varepsilon - \hat H_0 + E} \hat V |\psi^{(+)}\rangle \\ &= |\phi_{in}\rangle + \hat G_0^+(E) \hat V |\psi^{(+)}\rangle \\ \end{align} which is (1) exactly.

An Example: Scattering of a Massive Particle off a Potential in 3D

Say that we have a particle of mass \(m\) and a potential that only depends on the particle's position relative to the origin, or \(\vec r\). \[ \hat H_0 = \frac{\hat p^2}{2m}, \quad \langle\vec r | \hat V | \vec r'\rangle = V(r)\delta^{(3)}(\vec r - \vec r') \iff \hat V|\vec r\rangle = V(\vec r)|\vec r\rangle \] the eigenstates of \(\hat H_0\) are \(|\vec k\rangle = |k, \hat k\rangle\) with energy \(\frac{\hbar^2k^2}{2m}\), where \(\langle\vec r | \vec k\rangle = \frac{1}{(2\pi)^{3/2}}e^{i\vec k\cdot\vec r}\) (plane waves) and \(\langle \vec k|\vec k'\rangle = \delta^{(3)}(\vec k - \vec k')\). We now know that: \[ |\psi^+_{\alpha E}\rangle = |\phi_{\alpha E}\rangle + \hat G^+_0(E)\hat V|\psi^+_{\alpha E}\rangle \] but because energy \(E\) is in terms of \(k\): \[ \delta(E-E') = \frac{\delta(k-k')}{dE/dk} = \delta(E-E') = \frac{\delta(k-k')}{\hbar^2k/m} \] we can identify our states by \(\vec k\) instead of \(E\), it would just have different normalization. So the relationship \[ |\psi^+_{\vec k}\rangle = |\vec k\rangle + \hat G^+_0(E)\hat V|\psi^+_{\vec k}\rangle \] works just fine. Now we begin to solve this for \(|\psi^+_{\vec k}\rangle\). \begin{align} |\psi^+_{\vec k}\rangle &= |\vec k\rangle + \hat G^+_0(E)\hat V|\psi^+_{\vec k}\rangle \\ &= |\vec k\rangle + \int d^3 k'|\vec k'\rangle\langle\vec k'|\frac{1}{E - \hat H_0 + i0^+}\hat V|\psi^+_{\vec k}\rangle \\ &= |\vec k\rangle + \int d^3 k'|\vec k'\rangle\frac{1}{E - \frac{\hbar^2k'^2}{2m} + i0^+}\langle\vec k'|\hat V|\psi^+_{\vec k}\rangle \\ \end{align} This matrix element \(\langle\vec k'|\hat V|\psi^+_{\vec k}\rangle\) is sometimes called \(T^{(+)}_{\vec k', \vec k}\), or the off-shell T-matrix element, where off-shell indicates that the ket and the bra states have different energies. Remember that we saw this at the end of the introduction section.

Continue solving, using \(E - \frac{\hbar^2k'^2}{2m} = \frac{\hbar^2}{2m}(k^2 - k'^2)\): \begin{align} |\psi^+_{\vec k}\rangle &= |\vec k\rangle + \int d^3 k'|\vec k'\rangle\frac{1}{E - \frac{\hbar^2k'^2}{2m} + i0^+}\langle\vec k'|\hat V|\psi^+_{\vec k}\rangle \\ &= |\vec k\rangle + \int d^3 k'|\vec k'\rangle\frac{1}{\frac{\hbar^2}{2m}(k^2 - k'^2) + i0^+}\langle\vec k'|\hat V|\psi^+_{\vec k}\rangle \\ &= |\vec k\rangle + \frac{2m}{\hbar^2}\int d^3 k'|\vec k'\rangle\frac{1}{k^2 - k'^2 + i0^+}\langle\vec k'|\hat V|\psi^+_{\vec k}\rangle \\ \text{Using } \hat 1 &= \int d^3r'|\vec r'\rangle\langle\vec r'| \\ &= |\vec k\rangle + \frac{2m}{\hbar^2}\int d^3 k' |\vec k'\rangle \frac{1}{k^2 - k'^2 + i0^+} \int d^3r' \langle\vec k'|\vec r'\rangle\langle\vec r'|\hat V|\psi^+_{\vec k}\rangle \\ &= |\vec k\rangle + \frac{2m}{\hbar^2}\int d^3 k' |\vec k'\rangle \frac{1}{k^2 - k'^2 + i0^+} \int d^3r' \langle\vec k'|\vec r'\rangle V(\vec r')\langle\vec r'|\psi^+_{\vec k}\rangle \\ \langle\vec r|\psi^+_{\vec k}\rangle &= \langle\vec r|\vec k\rangle + \frac{2m}{\hbar^2}\int d^3 k' \langle\vec r|\vec k'\rangle \frac{1}{k^2 - k'^2 + i0^+} \int d^3r' \langle\vec k'|\vec r'\rangle V(\vec r')\langle\vec r'|\psi^+_{\vec k}\rangle \\ &= \frac{e^{i\vec k\cdot\vec r}}{(2\pi)^{3/2}} + \frac{2m}{\hbar^2}\int d^3 k' \frac{e^{i\vec k'\cdot\vec r}}{(2\pi)^{3/2}} \frac{1}{k^2 - k'^2 + i0^+} \int d^3r' \frac{e^{-i\vec k'\cdot\vec r'}}{(2\pi)^{3/2}} V(\vec r')\langle\vec r'|\psi^+_{\vec k}\rangle \\ &= \frac{e^{i\vec k\cdot\vec r}}{(2\pi)^{3/2}} + \frac{2m}{(2\pi)^3\hbar^2}\int d^3 k' e^{i\vec k'\cdot\vec r} \frac{1}{k^2 - k'^2 + i0^+} \int d^3r' e^{-i\vec k'\cdot\vec r'} V(\vec r')\psi^+_{\vec k}(\vec r') \\ &= \frac{e^{i\vec k\cdot\vec r}}{(2\pi)^{3/2}} + \frac{2m}{(2\pi)^3\hbar^2} \int d^3r' V(\vec r')\psi^+_{\vec k}(\vec r') \int d^3 k' \frac{e^{i\vec k'\cdot(\vec r-\vec r')}}{k^2 - k'^2 + i0^+} \end{align} We need to use Cauchy integration to evaluate the integral with respect to \(d^3k'\) and I'm not doing that. We essentially find that: \[ \int d^3 k' \frac{e^{i\vec k'\cdot(\vec r-\vec r')}}{k^2 - k'^2 + i0^+} = -\frac{2\pi^2}{|\vec r-\vec r'|}e^{ik|\vec r - \vec r'|} \] This result is quite important because we see the \(\vec k'\) term vanish. Which means that we get: \begin{align} \psi^+_{\vec k}(\vec r) &= \frac{e^{i\vec k\cdot\vec r}}{(2\pi)^{3/2}} - \frac{2m \cdot 2\pi^2}{(2\pi)^3\hbar^2} \int d^3r' V(\vec r')\psi^+_{\vec k}(\vec r') \frac{e^{ik|\vec r - \vec r'|}}{|\vec r-\vec r'|} \\ &= \frac{e^{i\vec k\cdot\vec r}}{(2\pi)^{3/2}} - \frac{m}{2\pi\hbar^2} \int d^3r' V(\vec r')\psi^+_{\vec k}(\vec r') \frac{e^{ik|\vec r - \vec r'|}}{|\vec r-\vec r'|} \end{align} The first term in this expression for \(\psi^+_{\vec k}(\vec r)\) is a single, clean, incoming plane wave.
The second term contains \(\frac{e^{ik|\vec r - \vec r'|}}{|\vec r-\vec r'|}\), which is a spherical wave. The full integral thus represents a linear combination of outgoing spherical waves, with one spherical wave emitted from each point \(\vec r'\) where \(V(\vec r')\psi^+_{\vec k}(\vec r')\) is non-zero.

Each of these spherical waves has momentum \(\hbar k\) and wavelength \(\frac{2\pi}{k}\), which is the same as the incoming plane wave. Note that this is a result of the \(\vec k'\) vanishing after Cauchy integration, and means that the possible outgoing spherical waves have the same energy as the incoming wave, which makes sense since energy must be conserved.

As this is a superposition, the particle could be in any of these states after scattering, but for large \(\vec r\), we very roughly get: \begin{align} \psi^+_{\vec k}(\vec r) &\approx \frac{e^{i\vec k\cdot\vec r}}{(2\pi)^{3/2}} - \frac{m}{2\pi\hbar^2} \int d^3r' V(\vec r')\psi^+_{\vec k}(\vec r') \frac{e^{ikr}}{r} \\ &= \frac{e^{i\vec k\cdot\vec r}}{(2\pi)^{3/2}} - \frac{e^{ikr}}{r} \frac{m}{2\pi\hbar^2} \int d^3r' V(\vec r')\psi^+_{\vec k}(\vec r') \end{align} from which we see that the outgoing component at large distances is one large spherical wave with amplitude \(\frac{m}{2\pi\hbar^2} \int d^3r' V(\vec r')\psi^+_{\vec k}(\vec r') \). Essentially, we see all the smaller, individual possible outgoing spherical waves compound together into one large spherical wave at large distances. Again, this is a very rough approximation; we will be more careful with it when we find the scattering cross section later.

Looking at the region close to the interaction center, we see something like this:


In our expression for \(\psi^+_{\vec k}(\vec r)\), the incoming plane wave component doesn't disappear after it reaches the potential; it's just \(\frac{e^{i\vec k\cdot\vec r}}{(2\pi)^{3/2}}\) and it simply continues on. Obviously if this were physically the case, then the outgoing flux is most certainly not equal to the incoming flux. This means that the scattered portion in the \(\vec k\) direction must cancel out the incoming beam; in other words it must be anti-phase with the incoming beam.

The scattering cross section. At large distances, how likely is it that the incoming particle scatters at a solid angle \(d\Omega\)? The scattering cross section tells us this. Essentially we want to know how many particles (during repeat experiments) scatter in that solid angle, given the number of particles that pass through a cross section before colliding with the target.

We start with our last result: \begin{align} \psi^+_{\vec k}(\vec r) &= \frac{e^{i\vec k\cdot\vec r}}{(2\pi)^{3/2}} - \frac{m}{2\pi\hbar^2} \int d^3r' V(\vec r')\psi^+_{\vec k}(\vec r') \frac{e^{ik|\vec r - \vec r'|}}{|\vec r-\vec r'|} \end{align} and because we're evaluating at large distances, we know that: \[ |\vec r| \gg \frac{2\pi}{k}, \quad |\vec r| \gg \text{Range}(V), \quad |r'| \ll |r| \] We use this to re-write \(|\vec r - \vec r'|\): \begin{align} |\vec r - \vec r'| &= \sqrt{r^2 + r'^2 - 2\vec r\cdot\vec r'} \\ &= r\sqrt{1 + (r'/r)^2 - 2(\hat r/r)\cdot\vec r'} \\ \text{Using } \sqrt{1 + x}\ &\approx 1 + x/2 \text{ for small x:} \\ &= r - \hat r\cdot\vec r' + o((r'/r)^2) \end{align} so that \begin{align} \psi^+_{\vec k}(\vec r) &= \frac{e^{i\vec k\cdot\vec r}}{(2\pi)^{3/2}} - \frac{m}{2\pi\hbar^2} \int d^3r' V(\vec r')\psi^+_{\vec k}(\vec r') \frac{e^{ik(r - \hat r\cdot\vec r')}}{r - \hat r\cdot\vec r'} \end{align} And, using the approximation \(\frac{1}{1-x}\approx1 + x\) for small \(x\): \begin{align} \frac{1}{r - \hat r\cdot\vec r'} &= \frac{1}{r}\frac{1}{1 - \hat r\cdot\vec r'/r} \\ &\approx \frac{1}{r}(1 + \frac{\hat r\cdot\vec r'}{r}) \\ &\approx \frac{1}{r} \end{align} which means that we now have: \begin{align} \psi^+_{\vec k}(\vec r) &= \frac{e^{i\vec k\cdot\vec r}}{(2\pi)^{3/2}} - \frac{m}{2\pi\hbar^2} \int d^3r' V(\vec r')\psi^+_{\vec k}(\vec r') \frac{e^{ik(r - \hat r\cdot\vec r')}}{r} \\ &= \frac{e^{i\vec k\cdot\vec r}}{(2\pi)^{3/2}} - \frac{m}{2\pi\hbar^2} \int d^3r' V(\vec r')\psi^+_{\vec k}(\vec r') \frac{e^{ik(r )}}{r} e^{- ik\hat r\cdot\vec r'} \\ &= \frac{e^{i\vec k\cdot\vec r}}{(2\pi)^{3/2}} - \frac{m}{2\pi\hbar^2} \frac{e^{ik(r )}}{r} \int d^3r' V(\vec r')\psi^+_{\vec k}(\vec r') e^{- ik\hat r\cdot\vec r'} \end{align} Now we look at \(e^{- ik\hat r\cdot\vec r'}\). \(\vec r\) is the position of the scattered particle relative to the interaction center, and \(\vec k'\) is the wavevector of the scattered particle, hence the directions of \(\vec k'\) and \(\vec r\) are the same. We ALSO know that the magnitudes of \(\vec k\) and \(\vec k'\) are the same at large distances. So, \(k\hat r = \vec k'\), and we can write \(e^{- ik\hat r\cdot\vec r'}\) as \(e^{- i\vec k'\cdot\vec r'}\) instead: \begin{align} \psi^+_{\vec k}(\vec r)&= \frac{e^{i\vec k\cdot\vec r}}{(2\pi)^{3/2}} - \frac{m}{2\pi\hbar^2} \frac{e^{ik(r )}}{r} \int d^3r' V(\vec r')\psi^+_{\vec k}(\vec r') e^{- i\vec k'\cdot\vec r'} \end{align} At this point, we use the first Born Approximation to find an adequate solution to the integral. Recall from the end of the introduction that we defined: \begin{align} |\psi_{\alpha E}^\pm\rangle &= \sum_{n=0}^\infty \left[\hat G_0^\pm(E)\hat V\right]^n|\phi_{\alpha E}\rangle \end{align} If we only employ the zero-th order term, \(|\psi_{\alpha E}^\pm\rangle\approx |\phi_{\alpha E}\rangle\). Thus we approximate \(\psi^+_{\vec k}(\vec r')\) as plane wave \(\frac{1}{(2\pi)^{3/2}}e^{i\vec k\cdot\vec r'}\): \begin{align} \psi^+_{\vec k}(\vec r) &= \frac{e^{i\vec k\cdot\vec r}}{(2\pi)^{3/2}} - \frac{m}{2\pi\hbar^2} \frac{e^{ik(r )}}{r} \int d^3r' V(\vec r') \frac{1}{(2\pi)^{3/2}}e^{i\vec k\cdot\vec r'} e^{- i\vec k'\cdot\vec r'} \\ &= \frac{e^{i\vec k\cdot\vec r}}{(2\pi)^{3/2}} - \frac{m}{2\pi\hbar^2} \frac{e^{ik(r )}}{r} \frac{1}{(2\pi)^{3/2}} \int d^3r' V(\vec r') e^{-i(\vec k' - \vec k)\cdot\vec r'} \end{align} If momentum is \(\hbar \vec k\), then \(\vec k'-\vec k = \Delta\vec q/\hbar\), where \(\Delta q\) is the change in momentum. Then our wave function becomes: \begin{align} \psi^+_{\vec k}(\vec r) &= \frac{e^{i\vec k\cdot\vec r}}{(2\pi)^{3/2}} - \frac{m}{2\pi\hbar^2} \frac{e^{ik(r )}}{r} \frac{1}{(2\pi)^{3/2}} \int d^3r' V(\vec r') e^{-i \Delta\vec q\cdot\vec r'/\hbar} \end{align} where \(e^{-i \Delta\vec q\cdot\vec r'/\hbar}\) is a momentum boost. Thus we see the particle scatters and changes momentum with \(\Delta\vec q\) (the magnitude of the momentum is the same, but the direction changes from \(\hat k\) to \(\hat k'\)).

This looks also like the Fourier transform in space of the potential. In other words, the potential itself has a distribution of momenta, and the incoming particle can acquire those distribution of momenta; the particle gets a kick from from the potential by that momentum... I think.

Notice also that nothing in the integrand now depends on \(r\). Let's pretend we never use the first Born Approximation and we have just used \(k\hat r = \vec k'\). We can do the following: \begin{align} \psi^+_{\vec k}(\vec r) &= \frac{e^{i\vec k\cdot\vec r}}{(2\pi)^{3/2}} - \frac{m}{2\pi\hbar^2} \frac{e^{ik(r )}}{r} \int d^3r' V(\vec r')\psi^+_{\vec k}(\vec r') e^{- i\vec k'\cdot\vec r'} \\ &= \frac{e^{i\vec k\cdot\vec r}}{(2\pi)^{3/2}} - \frac{m}{2\pi\hbar^2} \frac{e^{ik(r )}}{r} (2\pi)^{3/2} \int d^3r' V(\vec r') \langle \vec r' | \psi^+_{\vec k}\rangle \frac{e^{- i\vec k'\cdot\vec r'}}{(2\pi)^{3/2}} \\ &= \frac{e^{i\vec k\cdot\vec r}}{(2\pi)^{3/2}} - \frac{m}{2\pi\hbar^2} \frac{e^{ik(r )}}{r} (2\pi)^{3/2} \int d^3r' V(\vec r') \langle \vec r' | \psi^+_{\vec k}\rangle \langle\vec k'|\vec r'\rangle \\ &= \frac{e^{i\vec k\cdot\vec r}}{(2\pi)^{3/2}} - \frac{m}{2\pi\hbar^2} \frac{e^{ik(r )}}{r} (2\pi)^{3/2} \int d^3r' \langle\vec k'|\vec r'\rangle V(\vec r') \langle \vec r' | \psi^+_{\vec k}\rangle \\ &= \frac{e^{i\vec k\cdot\vec r}}{(2\pi)^{3/2}} - \frac{m}{2\pi\hbar^2} \frac{e^{ik(r )}}{r} (2\pi)^{3/2} \int d^3r' \langle\vec k'|\vec r'\rangle \langle \vec r' |\hat V| \psi^+_{\vec k}\rangle \\ &= \frac{e^{i\vec k\cdot\vec r}}{(2\pi)^{3/2}} - \frac{m}{2\pi\hbar^2} \frac{e^{ik(r )}}{r} (2\pi)^{3/2} \langle\vec k'|\hat V| \psi^+_{\vec k}\rangle \\ \end{align} Since we have shown that all of the \(\vec k'\)'s have the same energy as \(\vec k\), \(\langle\vec k'|\hat V| \psi^+_{\vec k}\rangle\) is what's known as the on-shell T-matrix, \(T_{\vec k', \vec k}\). Thus we can write the wavefunction as: \begin{align} \psi^+_{\vec k}(\vec r) &= \frac{e^{i\vec k\cdot\vec r}}{(2\pi)^{3/2}} - \frac{m}{2\pi\hbar^2} \frac{e^{ik(r )}}{r} (2\pi)^{3/2} T_{\vec k', \vec k} \\ &= \phi_{\vec k}(\vec r) - \frac{m\sqrt{2\pi}}{\hbar} \frac{e^{ik(r )}}{r} T_{\vec k', \vec k} \\ \end{align} (again, this is the incoming plane wave and the scattered spherical wave).

We can find the scattering cross-section now by finding the incoming and outgoing flux. Say that we know that the density of charge is \(\rho = |\psi(\vec r)|^2\), and that the continuity equation is \(\dot\rho = -\vec\nabla\cdot\vec j\), for density of current \(\vec j\).

I think this is partially because in general, \(\rho = q|\psi(\vec r)|^2\) for a particle of charge q, because \(|\psi(\vec r)|^2\) is the probability density of finding the particle at location \(\vec r\) and in quantim mechanics, a particle may not have a definite position... and I guess we use \(q=1\).

Using these two equations we can determine an expression for \(\vec j\): \begin{align} \dot\rho &= \partial_t(|\psi(\vec r)|^2) \\ &= \partial_t(\psi(\vec r)\psi^*(\vec r)) \\ &= \psi(\vec r)\dot\psi^*(\vec r) + \psi^*(\vec r)\dot\psi(\vec r) \\ \text{Using } \hat H = \frac{\hat p^2}{2m} + \hat V, &\quad i\hbar\dot\psi = \hat H\psi \implies \dot\psi = \frac{\hat H}{i\hbar}\psi \\ &= \psi\left(\frac{\hat H}{i\hbar}\psi \right)^* + \psi^*\left(\frac{\hat H}{i\hbar}\psi \right) \\ &= \left(\frac{\hat p^2\psi}{2mi\hbar} \right)^*\psi + \left(\frac{\hat V}{i\hbar}\psi \right)^*\psi + \psi^*\left(\frac{\hat p^2\psi}{2mi\hbar} \right) + \psi^*\frac{\hat V}{i\hbar}\psi \\ &= \left(\frac{\hat p^2\psi}{2mi\hbar} \right)^*\psi - \frac{\hat V\psi^* \psi}{i\hbar} + \psi^*\left(\frac{\hat p^2\psi}{2mi\hbar} \right) + \frac{\hat V\psi^*\psi}{i\hbar} \\ &= \left(\frac{\hat p^2\psi}{2mi\hbar} \right)^*\psi + \psi^*\left(\frac{\hat p^2\psi}{2mi\hbar} \right) \\ \text{Using }\hat p^2 &= -\hbar^2\nabla^2 \\ &= \left(\frac{-\hbar^2\nabla^2\psi}{2mi\hbar} \right)^*\psi + \psi^*\left(\frac{-\hbar^2\nabla^2\psi}{2mi\hbar} \right) \\ &= -\frac{\hbar^2}{2mi\hbar}\left(-\nabla^2\psi^*\psi + \psi^*\nabla^2\psi\right) \\ &= \frac{i\hbar}{2m}\left(-\nabla^2\psi^*\psi + \psi^*\nabla^2\psi\right) \\ &= -\vec\nabla\cdot\left(-\frac{i\hbar}{2m}(-\vec\nabla\psi^*\psi + \psi^*\vec\nabla\psi)\right) \\ &= -\vec\nabla\cdot\left(\frac{\hbar}{2mi}(\psi^*\vec\nabla\psi - \psi\vec\nabla\psi^*)\right) \end{align} According to the continuity equation, this must be equal to \(\dot\rho = -\vec\nabla\cdot\vec j\), so we know that: \[ \vec j = \frac{\hbar}{2mi}(\psi^*\vec\nabla\psi - \psi\vec\nabla\psi^*) \] We use this to find the density of current/flux for the incoming plane wave: \[ \vec j_{in} = \frac{\hbar}{2mi}\frac{1}{{(2\pi)^{3/2}}^2}\left\{e^{-i\vec k\cdot\vec r}i\vec ke^{i\vec k\cdot\vec r} - e^{i\vec k\cdot\vec r}(-i\vec k)e^{-i\vec k\cdot\vec r}\right\} = \frac{\hbar k}{(2\pi)^3m} \] and the flux for the outgoing wave: \[ \vec j_{out} = \frac{\hbar}{2mi}(\psi^*\vec\nabla\psi - \psi\vec\nabla\psi^*) , \quad \text{for } \psi = \frac{m\sqrt{2\pi}}{\hbar} \frac{e^{ik(r )}}{r} T_{\vec k', \vec k} \] (we actually didn't do this in class, but to leading order in \(\frac{1}{r}\), we get...) \[ \vec j_{out} \cdot\hat k' = \frac{2\pi m}{\hbar^3r^2}k|T_{\vec k', \vec k}|^2 \] this is the flux per unit of solid angle. The cross section is the ration of the flux per solid angle to the incoming flux: \[ \frac{d\sigma}{d\Omega} = \frac{2\pi m^2}{\hbar^3}\frac{(2\pi)^3}{\hbar}|T_{\vec k', \vec k}|^2 = \frac{(2\pi)^4 m^2}{\hbar^4}|T_{\vec k', \vec k}|^2 \] We can verify that this has correct units:
  • The units of the matrix element are the units of the potential (so energy) times the units of \(\langle \vec k'|\psi^+_{\vec k}\rangle\); these are normalized to be \(\delta^{(3)}(\vec k'-\vec k)\), so they have the same units as \(\frac{1}{k^3}\), which are \(L^3\).

    The matrix element has units EL^3.
  • The units from the coefficients are \(\frac{M^2}{(ET)^4}\)
  • The overall units are: \[ \frac{M^2}{(ET)^4}(EL^3)^2 = \frac{M^2E^2L^6}{E^4T^4} = L^2 \] or units of area, which is correct for the cross section.

Miscellaneous Points

Being controlled in the past/future. Recall that being controlled in the past/future means that there is only one channel for incoming/outgoing states, respectively. Also recall that the states \(|\psi^\pm_{\alpha E}\rangle\) are stationary, but we can define wave packets that are not stationary, e.g.: \[ |\psi(t=0)\rangle = \sum_\alpha\int dE|\psi^+_{\alpha E}\rangle c_{\alpha E}, \quad \sum_\alpha\int dE |c_{\alpha E}|^2 = 1 = \langle\psi|\psi\rangle \] where \(c_{\alpha E} = \langle \psi^+_{\alpha E}|\psi(t=0)\rangle\). We can also have time dependence: \[ |\psi(t)\rangle = \sum_\alpha\int dE e^{-iEt/\hbar} |\psi^+_{\alpha E}\rangle c_{\alpha E} \] We've looked at the generalized eigenstates in the far past and future; let's look at this wavepacket in the far past, at large negative time. Starting with the Lipmann-Schwinger equation: \begin{align} |\psi_{\alpha E}^\pm\rangle &= |\phi_{\alpha E}\rangle + \hat G_0^\pm(E)\hat V|\psi^\pm_{\alpha E}\rangle \\ &= |\phi_{\alpha E}\rangle + \sum_\beta\int dE'|\phi_{\beta E'}\rangle\langle\phi_{\beta E'} |\hat G_0^\pm(E)\hat V|\psi^\pm_{\alpha E}\rangle \\ \end{align} Now we plug this into our time-dependent wave packet: \begin{align} |\psi(t)\rangle &= \sum_\alpha\int dE e^{-iEt/\hbar} |\psi^+_{\alpha E}\rangle c_{\alpha E} \\ &= \sum_\alpha\int dE e^{-iEt/\hbar} \left( |\phi_{\alpha E}\rangle + \sum_\beta\int dE'|\phi_{\beta E'}\rangle\langle\phi_{\beta E'} |\hat G_0^+(E)\hat V|\psi^+_{\alpha E}\rangle \right) c_{\alpha E} \\ &= \sum_\alpha\int dE \left( e^{-iEt/\hbar}|\phi_{\alpha E}\rangle c_{\alpha E} + e^{-iEt/\hbar}\sum_\beta\int dE'|\phi_{\beta E'}\rangle\langle\phi_{\beta E'} |\hat G_0^+(E)\hat V|\psi^+_{\alpha E}\rangle c_{\alpha E} \right) \\ &= \sum_\alpha\int dE e^{-iEt/\hbar}|\phi_{\alpha E}\rangle c_{\alpha E} + \sum_{\alpha, \beta}\int dE \int dE' e^{-iEt/\hbar}|\phi_{\beta E'}\rangle\langle\phi_{\beta E'} |\hat G_0^+(E)\hat V|\psi^+_{\alpha E}\rangle c_{\alpha E} \end{align} The first term, \(\sum_\alpha\int dE e^{-iEt/\hbar}|\phi_{\alpha E}\rangle c_{\alpha E} \), tells us that one component of the wavepacket is a free wavepacket, or a linear combination of plane waves that use the same expansion coefficients as the original wavepacket, \(c_{\alpha E}\).

The second term can be cleaned up a bit: \begin{align} &\sum_{\alpha, \beta}\int dE \int dE' e^{-iEt/\hbar}|\phi_{\beta E'}\rangle\langle\phi_{\beta E'} |\hat G_0^+(E)\hat V|\psi^+_{\alpha E}\rangle c_{\alpha E} \\ &= \sum_{\beta} \int dE' |\phi_{\beta E'}\rangle \sum_{\alpha}\int dE \frac{e^{-iEt/\hbar}}{E-E'+i0^+} \langle\phi_{\beta E'} |\hat V|\psi^+_{\alpha E}\rangle c_{\alpha E} \\ &= \sum_{\beta} \int dE' |\phi_{\beta E'}\rangle \sum_{\alpha}\int dE \frac{e^{-iEt/\hbar} T^+_{\beta E', \alpha E} c_{\alpha E}}{E-E'+i0^+} \end{align} To solve this integral with respect to \(E\), we need to take the contour integral where \(E\) is complex, and close the countour where the integrand converges. The integrand has an \(e^{-iEt/\hbar}\). If we write \(E = E_{Re} + iE_{Im}\), this becomes: \[ e^{-iEt/\hbar} = e^{-i(E_{Re} + iE_{Im})t/\hbar} = e^{-iE_{Re}t/\hbar} e^{ E_{Im}t/\hbar} \] The \(e^{-iE_{Re}t/\hbar}\) term oscillates (it can be written as a sinusoid using Euler's identity), so the \(e^{ E_{Im}t/\hbar}\) term determines where the integrand converges. For a negative time \(t\), this is clearly where \(E_{Im}\), or the imaginary part of the emergy, is positive. Thus we close the contour above the real axis.

The pole of this integrand, however, is slightly below the real axis, at \(E'-i0^+\). Thus this integral is simply 0 for negative \(t\).

This means that if we reverse time for a wavepacket built from generalized eigenstates \(|\psi^\pm_{\alpha E}\rangle\), we only see the free wave packet, \(|\psi(t)\rangle = \sum_\alpha\int dE e^{-iEt/\hbar}|\phi_{\alpha E}\rangle c_{\alpha E}\). This formalizes the notion that the wavepacket is controlled in the past. Basically, it is prepared as a free wavepacket and evolves as a combination of scattering states with the same coefficients as the coefficients for \(|\phi_{\alpha E}\rangle\) in the far past.

As a side note, this means we can write: \[ c_{\alpha E} \approx e^{iEt/\hbar} \langle\phi_{\alpha E} | \psi(t)\rangle \] but as we know from earlier: \[ c_{\alpha E} = \langle \psi^+_{\alpha E}|\psi(t=0)\rangle = \langle \psi^+_{\alpha E}|\psi(t)\rangle e^{iEt/\hbar} \] Thus \(\langle \psi^+_{\alpha E}|\psi(t)\rangle \approx \langle\phi_{\alpha E} | \psi(t)\rangle\) for sufficiently large and negative time (that is, the overlap of the wavepacket with the full Hamiltonian eigenstates is approximately the same as the overlap with the unperturbed eigenstates).

The relationship between \(|\psi^+\rangle\) and \(|\psi^-\rangle\). The \(|\psi^+\rangle\) states for a complete basis for the continuum, and so do the \(|\psi^-\rangle\) states. We can define projectors as follows: \[ \hat 1 = \hat P_{bound} = \hat P_{continuum} - \sum_i|\psi_i\rangle \langle\psi_i| + \sum_\alpha\int dE|\psi^+_{\alpha, E}\rangle\langle\psi^+_{\alpha, E}| \] (note that we could also use the \(|\psi^-\rangle\) states to define \(\hat P_{continuum}\)). Where the bound eigentstates follow \(\hat H|\psi_i\rangle = E_i|\psi_i\rangle\), and are normalized so that \(\langle \psi_j|\psi_i\rangle = \delta_{ij}\). The continuum states of course, follow \(\hat H\psi^+_{\alpha, E} = E|\psi^+_{\alpha, E}\rangle\), and are normalized so that \(\langle\psi_i|\psi^+_{\alpha, E}\rangle = 0\) and \(\langle \psi^+_{\beta, E}|\psi^+_{\alpha, E}\rangle = \delta_{\beta, \alpha}\delta_{E'E}\).

Because \(|\psi^+\rangle\) form a complete basis, we can write \(|\psi^-\rangle\) as a linear combination of \(|\psi^+\rangle\): \[ |\psi^-_{\alpha, E}\rangle = \sum_\beta|\psi^+_{\beta, E}\rangle c_{\beta, \alpha} \] Using the Lipmann-Schwinger equation, we can also write: \begin{align} |\psi_{\alpha E}^+\rangle &= |\phi_{\alpha E}\rangle + \hat G_0^+(E)\hat V|\psi^+_{\alpha E}\rangle \\ |\psi_{\alpha E}^-\rangle &= |\phi_{\alpha E}\rangle + \hat G_0^-(E)\hat V|\psi^-_{\alpha E}\rangle \\ \end{align} We now define state \(|\Delta \psi_{\alpha E}\rangle = |\psi^+_{\alpha E}\rangle - |\psi^-_{\alpha E}\rangle\). \begin{align} |\Delta \psi_{\alpha E}\rangle &= |\psi^+_{\alpha E}\rangle - |\psi^-_{\alpha E}\rangle \\ &= |\phi_{\alpha E}\rangle + \hat G_0^+(E)\hat V|\psi^+_{\alpha E}\rangle - |\phi_{\alpha E}\rangle - \hat G_0^-(E)\hat V|\psi^-_{\alpha E}\rangle \\ &= \hat G_0^+(E)\hat V|\psi^+_{\alpha E}\rangle - \hat G_0^-(E)\hat V|\psi^-_{\alpha E}\rangle \\ &= \hat G_0^+(E)\hat V|\psi^+_{\alpha E}\rangle - \hat G_0^-(E)\hat V\left\{|\psi^+_{\alpha E}\rangle - |\Delta\psi_{\alpha E}\rangle\right\} \\ &= \hat G_0^+(E)\hat V|\psi^+_{\alpha E}\rangle - \hat G_0^-(E)\hat V|\psi^+_{\alpha E}\rangle + \hat G_0^-(E)\hat V|\Delta\psi_{\alpha E}\rangle \\ &= \left[\hat G_0^+(E)- \hat G_0^-(E)\right]\hat V|\psi^+_{\alpha E}\rangle + \hat G_0^-(E)\hat V|\Delta\psi_{\alpha E}\rangle \\ \end{align} Let's expand \(\hat G_0^+(E)- \hat G_0^-(E)\): \begin{align} \hat G_0^+(E)- \hat G_0^-(E) &= \frac{1}{E-\hat H_0 + i0^+} - \frac{1}{E-\hat H_0 - i0^+} \\ &= \left(\frac{1}{E-\hat H_0 + i0^+} - \frac{1}{E-\hat H_0 - i0^+}\right) \sum_\beta\int dE'|\phi_{\beta E'}\rangle\langle \phi_{\beta E'}| \\ &= \sum_\beta \int dE' \left(\frac{1}{E-E' + i0^+} - \frac{1}{E-E' - i0^+}\right) |\phi_{\beta E'}\rangle\langle \phi_{\beta E'}| \\ \end{align} In general, \(\frac{1}{x + i0^+} = \frac{\mathcal P}{x} - i\pi\delta(x)\) so \(\frac{1}{x+i0^+} - \frac{1}{x-i0^+} = -2i\pi\delta(x)\): \begin{align} \hat G_0^+(E)- \hat G_0^-(E) &= -2i\pi\sum_\beta\int dE' \delta(E-E')|\phi_{\beta E'}\rangle\langle \phi_{\beta E'}| \\ &= -2i\pi\sum_\beta|\phi_{\beta E}\rangle\langle \phi_{\beta E}| \end{align} which is apparently a density of projector on energy shell with level \(E\). Plugging this in: \begin{align} |\Delta \psi_{\alpha E}\rangle &= \left[\hat G_0^+(E)- \hat G_0^-(E)\right]\hat V|\psi^+_{\alpha E}\rangle + \hat G_0^-(E)\hat V|\Delta\psi_{\alpha E}\rangle \\ &= -2i\pi\sum_\beta|\phi_{\beta E}\rangle\langle \phi_{\beta E}|\hat V|\psi^+_{\alpha E}\rangle + \hat G_0^-(E)\hat V|\Delta\psi_{\alpha E}\rangle \\ &= \sum_\beta-2i\pi T^+_{\beta\alpha}(E) |\phi_{\beta E}\rangle + \hat G_0^-(E)\hat V|\Delta\psi_{\alpha E}\rangle \\ \end{align} Notice how similar in structure this is to \( |\psi_{\alpha E}^-\rangle = |\phi_{\alpha E}\rangle + \hat G_0^-(E)\hat V|\psi^-_{\alpha E}\rangle \\ \). If we multiply by \(-2i\pi T^+_{\beta\alpha}(E)\) on both sides: \[ -2i\pi T^+_{\beta\alpha}(E)|\psi_{\alpha E}^-\rangle = -2i\pi T^+_{\beta\alpha}(E) |\phi_{\alpha E}\rangle + -2i\pi T^+_{\beta\alpha}(E) \hat G_0^-(E)\hat V|\psi^-_{\alpha E}\rangle \] and take the sum over all \(\beta\) on both sides: \[ \sum_\beta-2i\pi T^+_{\beta\alpha}(E)|\psi_{\alpha E}^-\rangle = \sum_\beta-2i\pi T^+_{\beta\alpha}(E) |\phi_{\alpha E}\rangle + \sum_\beta-2i\pi T^+_{\beta\alpha}(E) \hat G_0^-(E)\hat V|\psi^-_{\alpha E}\rangle \] then say that \(\sum_\beta-2i\pi T^+_{\beta\alpha}(E)|\psi_{\alpha E}^-\rangle = |{\psi_{\alpha E}^-}'\rangle\) we get that: \[ |{\psi_{\alpha E}^-}'\rangle = \sum_\beta-2i\pi T^+_{\beta\alpha}(E) |\phi_{\alpha E}\rangle + \hat G_0^-(E) \hat V |{\psi_{\alpha E}^-}'\rangle \] which replicates the structure of \(|\Delta \psi_{\alpha E}\rangle \) exactly. We thus see that: \[ |\Delta \psi_{\beta E}\rangle = \sum_\beta |\psi_{\alpha E}^-\rangle(-2i\pi T_{\beta\alpha}(E)) \] Using this, we can update our definition of \(|\psi_{\alpha E}^+\rangle\): \begin{align} |\psi_{\alpha E}^+\rangle &= |\psi^-_{\alpha E}\rangle + |\delta\psi_{\alpha E}\rangle \\ &= |\psi^-_{\alpha E}\rangle + \sum_\beta |\psi_{\alpha E}^-\rangle(-2i\pi T_{\beta\alpha}(E)) \\ &= \sum_\beta |\psi^-_{\beta E}\rangle (\delta_{\alpha\beta}-2i\pi T_{\beta\alpha}(E)) \end{align} Recall that we've mentioned the on-shell probability amplitude/scattering matrix before. Here, we have the off-shell version, \(\mathcal S_{\beta E', \alpha E} = \langle \psi^-_{\beta E'} | \psi^+_{\alpha E}\rangle\). We can finally use it: \begin{align} \mathcal S_{\beta E', \alpha E} &= \langle \psi^-_{\beta E'} | \psi^+_{\alpha E}\rangle \\ &= \langle \psi^-_{\beta E'} | \left(\sum_\gamma |\psi^-_{\gamma E}\rangle (\delta_{\alpha\gamma}-2i\pi T_{\gamma\alpha}(E))\right) \\ &= \sum_\gamma \langle \psi^-_{\beta E'} |\psi^-_{\gamma E}\rangle (\delta_{\alpha\gamma}-2i\pi T_{\gamma\alpha}(E)) \\ &= \sum_\gamma \delta_{\beta\gamma}\delta(E'-E) (\delta_{\alpha\gamma}-2i\pi T_{\gamma\alpha}(E)) \\ &= \delta(E'-E) (\delta_{\alpha\beta}-2i\pi T_{\beta\alpha}(E)) \\ &= \delta(E'-E)\mathcal S_{\beta\alpha}(E) \end{align} where it turns out that \(\delta_{\alpha\beta}-2i\pi T_{\beta\alpha}(E)\) is the on-shell scattering matrix, \(\mathcal S_{\beta\alpha}(E)\). We unfortunately don't have time to go into depth about the scattering matrices, but they are like a transformation from one orthonormal basis to another where flux/probability is conserved, in a shell with a specific energy.

Scattering from a spherical potential, scattering phase shift. Let's look at the secial case of scattering by a spherical potential. Remember that if \(\hat H = \frac{\hat p^2}{2m} + V(r)\) and the potential is spherical, then \(\hat H, \hat L^2] = [\hat H, \hat L_z] = 0\), and we can separate the wavefunctions \(\psi_{Elm}(\vec r)\) into angular and radial components: \[ \psi_{Elm}(\vec r) = R_{El}(r)Y_{lm}(\hat R) \] We can further write the radial function in terms of the reduced radial function: \[ R_{El} = \frac{u_{EL}(r)}{r} \] where \(u_{El}(r)\) satisfies the radial TDSE: \[ -\frac{\hbar^2}{2m}u''_{El} + \frac{\hbar^2}{2mr^2} l(l+1)u_{El} + V(r)u_{El} = E u_{El} \] which has one term for the kinetic energy, one term from the repulsive "centrifugal potential", which is negligible for large \(r\), and the spherical potential itself. This is like a particle in one-dimension that ranges from 0 to \(\infty\) with an effective potential that is the spherical potential plus the centrifugal potential.

If the spherical potential decays as \(\frac{1}{r^2}\), asymptotically we expect that \(u_{El} \approx \sin(kr-l\pi/2+\delta_l(E))\), since at large \(r\), our TDSE should match that of a free wave. The phase shifts here are partially out of convention; the \(-l\pi/2\) is a result of the centrifugal potential and the \(\delta_l(E)\) is a result of \(V(r)\). If \(V(r) = 0\), then we simply have a free particle, and asymptotically, \(u_{El} \approx \sin(kr-l\pi/2)\).

We can define a function \(j_l(kr) = \frac{u_{El}(r)}{kr}\) for the case where \(kr\gg 1\) and the potential is 0: \[ j_l(kr) = \frac{\sin(kr-l\pi/2)}{kr} \] These are the spherical Bessel functions; spherical waves/radial functions for the eigenvectors of \(\frac{\hat p^2}{2m}\) in spherical coordinates (so they are also the eigenvectors for \(\hat L_2\) and \(\hat L_z\)).

In scattering, we are often concerned with plane waves, e.g. \(e^{i\vec k\cdot\vec r}\). This is an eigenvector of \(\hat H_0\) with specific energy, \(\frac{\hbar^2k^2}{2m}\). We can write it as a linear combination of spherical waves with the same \(k\) like so: \[ e^{i\vec k\cdot\vec r} = 4\pi\sum_{l=0}^\infty \sum_{m=-l}^l i^l j_l(kr) Y^*_{lm}(\hat k) Y_{lm}(\hat r) \] We don't derive this; he just gives it to us lol. Essentially, this is how to write a plane wave as a linear combination of spherical waves, \(j_l(kr)\). Notice that this is a scalar since it is a function of a scalar product; the two angular functions are two tensors of rank \(l\) that combine to make a scalar function...

Let's look at the asymptotic part, \(j_l\): \begin{align} j_l(kr) &= \frac{\sin(kr-l\pi/2)}{kr} \\ &= \frac{e^{i(kr-l\pi/2)} - e^{-i(kr-l\pi/2)}}{2ikr} \\ &= \frac{1}{2ikr}\left(e^{-il\pi/2}e^{ikr} - e^{il\pi/2}e^{-ikr}\right) \end{align} If we use \({e^{i\pi/2}}^{-l} = \frac{1}{i^l}\) and \((e^{i\pi/2})^l = i^l\): \[ e^{i\vec k\cdot\vec r} = 4\pi\sum_{l=0}^\infty \sum_{m=-l}^l \frac{1}{2ikr} \left(e^{ikr} - i^{2l}e^{-ikr}\right) Y^*_{lm}(\hat k) Y_{lm}(\hat r) \] which has an incoming term \(- i^{2l}e^{-ikr}\) and an outgoing term \(e^{ikr}\) (note these are all over \(r\) from the \(\frac{1}{2ikr}\), so these are incoming and outgoing spherical waves). Thus we have successfully reproduced \(e^{i\vec k\cdot\vec r}\) as a linear combination of the spherical Bessel functions.

To reproduce a \(\psi^+\) state, we need to find the linear combination of solutions to the full Hamiltonian which (for large \(r\)) has an incoming component that coincides with a plane wave (so, what we found above for \(e^{i\vec k\cdot\vec r}\)). What we have right now for \(e^{i\vec k\cdot\vec r}\) is a solution to the unperturbed Hamiltonian only, as it's built out of \(j_l(kr)\), which are eigenstates of the unperturbed Hamiltonian. So while it matches the incoming component of \(\psi^+\), it does not match the scattered aftermath.

So, what do we use instead of \(j_l(kr)\)? We may want to first try \(u_{El} \approx \sin(kr-l\pi/2 + \delta_l(E))\) instead of \(u_{El} \approx \sin(kr-l\pi/2)\) inside of \(\frac{u_{El}(r)}{kr}\): \begin{align} \frac{u_{El}(r)}{kr} &= \frac{\sin(kr-l\pi/2 + \delta_l(E))}{kr} \\ &= \frac{e^{i(kr-l\pi/2 + \delta_l(E))} - e^{-i(kr-l\pi/2 + \delta_l(E))}}{2ikr} \\ &= \frac{1}{2ikr}\left(e^{-il\pi/2}e^{ikr}e^{i\delta_l} - e^{il\pi/2}e^{-ikr}e^{-i\delta_l}\right) \\ &= \frac{1}{2ikr}\left(\frac{1}{i^l}e^{ikr}e^{i\delta_l} - i^le^{-ikr}e^{-i\delta_l}\right) \\ \end{align} but if we plug this into the previous linear combination, we get: \begin{align} &4\pi\sum_{l=0}^\infty \sum_{m=-l}^l i^l \frac{1}{2ikr}\left(\frac{1}{i^l}e^{ikr}e^{i\delta_l} - i^le^{-ikr}e^{-i\delta_l}\right) Y^*_{lm}(\hat k) Y_{lm}(\hat r) \\ &= 4\pi\sum_{l=0}^\infty \sum_{m=-l}^l \frac{1}{2ikr}\left(e^{ikr}e^{i\delta_l} - i^{2l}e^{-ikr}e^{-i\delta_l}\right) Y^*_{lm}(\hat k) Y_{lm}(\hat r) \end{align} where the incoming term is \(- i^{2l}e^{-ikr}e^{-i\delta_l}\) instead of the incoming component we want it to be, \(- i^{2l}e^{-ikr}\). So, instead, we simply use \(e^{i\delta_l}\frac{u_{El}(r)}{kr}\), which makes the incoming components match that of a plane wave: \begin{align} (2\pi)^{3/2}\psi^+_{\vec k} &= 4\pi\sum_{l=0}^\infty \sum_{m=-l}^l i^l \frac{1}{2ikr}e^{i\delta_l}\left(\frac{1}{i^l}e^{ikr}e^{i\delta_l} - i^le^{-ikr}e^{-i\delta_l}\right) Y^*_{lm}(\hat k) Y_{lm}(\hat r) \\ &= 4\pi\sum_{l=0}^\infty \sum_{m=-l}^l \frac{1}{2ikr}e^{i\delta_l}\left(e^{ikr}e^{i\delta_l} - i^{2l}e^{-ikr}e^{-i\delta_l}\right) Y^*_{lm}(\hat k) Y_{lm}(\hat r) \\ &= 4\pi\sum_{l=0}^\infty \sum_{m=-l}^l \frac{1}{2ikr}\left(e^{ikr}e^{2i\delta_l} - i^{2l}e^{-ikr}\right) Y^*_{lm}(\hat k) Y_{lm}(\hat r) \end{align} This is now an exact solution of the full Hamiltonian, because it is a linear combination of actual eigenstates of the full \(\hat H\), and its incoming components match the incoming components of the plane wave.

We can see that all of the properties that we're interested in from the scattering are contained in the phase shift... In other words, all that differentiates this state \((2\pi)^{3/2}\psi^+_{\vec k}\) from that of the free wave \(e^{i\vec k\cdot\vec r}\) is the inclusion of the phase shift \(\delta_l(E)\) (and the following added factor of \(e^{i\delta_l}\)).

If we compute the scattering cross section, we would obtain: \[ \frac{d\sigma}{d\Omega} = \frac{1}{k^2}|\sum_{l=0}^\infty e^{i\delta_l}\sin(\delta_l)(2l + 1) P_l\cos(\theta)|^2 \] where \(P_l\cos(\theta)\) is the Legendre polynomial, and \(\theta\) is the scattering angle between \(\vec k\) and \(\vec k'\). And we would eventually find that: \[ \sigma_{total} = \frac{4\pi^2}{k^2}\sum_l(2l + 1)\sin^2(\delta_l) \] Clearly, if we know \(\delta_l\) for all \(l\), we would know the scattering-cross section.

If all \(\delta_l=0\), then the potential has negligible asymptotic effect, and \(\hat H\)'s eigenstates are identical to \(\hat H_0\)'s (so there is no phase shift) and there is no scattering, and the scattering cross-section is 0.

We can also have \(\delta_l=0\) for \(l\gt0\) even if there is a potential that would have asymptotic affect; if \(k\to 0\), then \(\delta_{l\gt0}\to 0\). Essentially, at low energies, the centrifugal potential acts as a barrier for all \(l\gt0\), bouncing back the particle with any angular momentum before it can interact with the actual potential. You would only see the potential when there is no angular momentum, so \(l=0\). In this case, the total cross-section converges on a constant: \[ \sigma_{total} = \frac{4\pi^2}{k^2}\sin^2\delta_0 = 4\pi^2 a_0^2 \] for constant scattering length \(-a_0 = \frac{\sin\delta_0}{k}\) where \(k\to0\). This happens to be the radius of a hard potential sphere. Thus the cross section is four times the geometric cross-section of this potential sphere. At low energy, the scatterer only gives rise to spherical waves which emanate outwards from the center.
